# react-native-capture-and-share

An open-source React Native component for capturing a screenshot of any view and sharing it directly to social apps via a bottom tray with a carousel of share targets.

Originally built internally at Coinbase as "ShareTray"; this project is an open-source reimplementation.

## Status

Early scaffolding — see the [Share Tray OSS Linear project](https://linear.app/aaronpollock/project/share-tray-oss-ae2e0fdea58d) for tracked work.

## Planned stack

- [react-native-view-shot](https://github.com/gre/react-native-view-shot) for capturing the wrapped view
- [react-native-share](https://github.com/react-native-share/react-native-share) for the share-target API
- A Reanimated-based tray for native-thread animation
